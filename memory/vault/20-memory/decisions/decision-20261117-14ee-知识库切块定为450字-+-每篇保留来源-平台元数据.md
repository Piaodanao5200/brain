2026-11-17 用户决策并已落地 brain/library：

1) 检索切块：NO_SPLIT=False、TARGET=450（kb.py 顶部可改）。切多大取舍：不切=上下文全但定位粗，短文够用；450/600=平衡通用；250=定位准但易断语义。HARD=1400 不变。
2) 元数据：documents 加 source（原始URL/路径）与 platform（B站/抖音/小红书/YouTube/微信公众号/PDF…）。优先级：--source/--platform 参数 > md frontmatter > sidecar（meta set 改的有效值）> 自动推断（域名/扩展名）。meta show/set/list 管理有效值；音视频识别原件头部写入快照（captured 稳定日期，参与 sha，rebuild 一致）；markdown/reading frontmatter 同步带 source/platform。
3) sidecar：sources/.meta.json（sha→{source,platform}）与 .topics.json 并行，rebuild 不丢。

教训：把会变的元数据写进内容寻址文件必须用稳定字段，否则 rebuild 时 sha/doc_id 漂移（Windows 下 write_text 换行同理，要用 write_bytes）。
