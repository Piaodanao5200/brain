约定：回复闸等检查脚本（reply_gate.py、term_lint.py、kb_hint.mjs）按规则调用即可，不为确认参数去读源码。理由：规则只要求跑脚本，读源码属额外 token 开销；脚本是唯一真源，调用它、看退出码即可，不必把源码抄进上下文。例外：脚本报错、结果看不懂、或要改脚本时，才临时读一次源码排查。来源：2026-11-26 会话，用户在对比跑脚本/读源码后明确选「只跑脚本」并授权记录。
