## 现象

有人在记忆或 AGENTS.md 里写下 `npm run build`，后来项目换成 pnpm，文件没改。agent 照着跑，报错，然后开始 debug 这个"错误的问题"，浪费一整轮。

## 原因

文档里的命令是**副本**，副本必然滞后于真源。这个问题在多 agent 共享记忆时出现频率最高——每个 agent 都可能往文件里补一条命令。

## 解法

- 记忆里**永不复制命令**，只写"跑 `package.json` 里的 `build` 脚本"这类**指向**。
- 必须写命令时，只写一条，且放在唯一位置，其他条目引用它。
- 把 `kb lint` 接进 CI，检查重复定义与失效引用。

## 边界

对一次性脚本（如数据迁移）可以写完整命令，但要带日期，并在正文注明"一次性，已执行完"。
