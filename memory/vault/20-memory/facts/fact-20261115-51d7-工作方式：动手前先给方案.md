用户要求执行前先看到方案再开工。做模型调研时原话是「在执行前告诉我你的方案」，之后又在方案确认后才说「开始吧」。推断：涉及多步骤、要花时间或会产生文件的任务，应先给方案与范围，等他确认，不要直接开干。
