所有 agent 共用的项目统一放在 `D:\collaborative project\<项目名>\`；只有单个 agent 用的项目放它自己的目录（lead 用 `D:\deepseek\<项目名>\`）。

依据：用户 2026-11-15 口述，并当场把 `D:\brain` 整个迁到 `D:\collaborative project\brain`。

边界：判断标准是「别的 agent 会不会读写这个项目」。目录名带空格，命令里必须加引号。
