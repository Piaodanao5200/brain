豆包桌面客户端不向会话注入 brain 记忆库，但文件本身读得到：只要有平台偏好指名去读，agent 就能用文件工具读到 vault 或 MEMORY.md，不存在"读不到"。

依据：2026-11-18 实测会话 38454755670856450：首轮按偏好读 AGENTS.md 成功；随后 5 轮工具调用（扫桌面、装 CLI 等）里 0 次检索 vault，直到用户追问才读 INDEX。旧结论把"没调用工具"记成了"读不到"，属推断错误。

边界：偏好只保证读一次门牌，不保证触发检索；接入 hook 或 MCP 通道后本结论失效。
