遇到 MCP、hook、BM25 这类术语时反馈「没看懂」。有效的讲法是先用一句话说清它是什么、再给「没有它 vs 有它」的对比。给他做技术说明时，避免缩写与协议名堆叠，先讲能干什么再讲怎么实现。
