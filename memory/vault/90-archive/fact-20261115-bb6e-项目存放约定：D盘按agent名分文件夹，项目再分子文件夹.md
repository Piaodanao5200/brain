所有 agent 新建项目时，先在 D 盘根目录建一个以**自己名字**命名的文件夹，该 agent 的全部项目文件与缓存都放在里面；每个具体项目在其下再建一层子文件夹，用项目名命名，即 `D:/<agent名>/<项目名>/`。

依据：用户 2026-11-15 口述。目的是不同 agent 的产物互不覆盖，且从目录名就能看出是谁建的、属于哪个项目。

边界：只约束**新建**项目。已存在的 `D:/WorkBuddy/llm-ranking`、`D:/brain/` 保持原位不迁移，除非用户明确要求。文件夹名用 agent 自报的产品名（如 WorkBuddy、Claude-Code），不要用 `agent`、`AI` 这类通用词。
